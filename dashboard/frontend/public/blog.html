SEO Audit Results

Claude scores each article (22 checks + SEO/GEO) and results are stored in the dashboard SQLite (seo_audits table, same file as WordPress sync). Batches process posts that do not have an audit yet (newest in WordPress first), or that were changed in WordPress after their last audit. Click a row to expand failed criteria, model summary, and how to improve scores. Run WordPress Sync first. Uses ANTHROPIC_API_KEY; runs need the dashboard write token.

Rewrite Queue

Articles below the SEO threshold are rewritten locally (research + planning + Markdown writer ↔ reviewer + MD→HTML). Review each result, then use Upload to WordPress when satisfied to create a duplicate draft (live post unchanged). Stop skips the rest of the batch after the current article. Clear staging removes all local rewritten files and the staging index (and drops legacy rewrite tables in SQLite if present); it does not delete anything in WordPress. Requires ANTHROPIC_API_KEY (web search enabled for your org), WordPress credentials for upload, and write token for runs/upload.
